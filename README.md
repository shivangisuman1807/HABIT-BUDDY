# Habit Buddy 🐾

Habit Buddy is a cute habit-tracking web app with virtual pets and a gem-based reward/shop system.

## Current features

- Weekly and monthly habit tracking
- Calendar progress grid
- Gem rewards
- Pet selection and customizable pet name
- Pet happiness and hunger
- Pet treats and Treat Bag
- Gem shop with cart and checkout
- Feeding interactions
- Theme customization

## Run

Open `index.html` in a browser. No build step is required.

## GitHub Pages

Upload the contents of this folder to a GitHub repository, then enable:

**Settings → Pages → Deploy from a branch → `main` → `/ (root)`**

GitHub Pages will provide the live website URL.

## Project status

This is an MVP and is intended to be developed further. The app is currently kept mostly in `index.html` to make early development simple.
